# 安屿 · Android + PWA

面向18岁及以上舞蹈生的进食困扰支持原型。暖白与鼠尾草绿界面、云朵形象「小屿」，借鉴 CBT-E 的合作、自我观察与支持思路。它不提供诊断、实时监护或已经验证的治疗效果。

## 在线使用

- PWA：https://songlin99.github.io/anyu/
- Android：https://github.com/SongLin99/anyu/releases/latest
- AI 使用开发者单独提供的内测邀请码；邀请码不是 DeepSeek API Key。

## 已实现

- 四张欢迎页：理解压力、催吐与温和用词的对应图示、带来源的舞蹈生研究图表、改变与支持；成年确认及两道个性化选择题，6种原因与5种目标组合为30种起步计划。
- 冲动／实际催吐／确认当天没有发生分开记录；日历、补填、修改、删除、周回顾。
- 每条记录的一句支持与单独聊天共用目标、最近记录及对话上下文；删除源记录后不再发送关联反馈。
- 本设备 IndexedDB + AES-GCM 保存；密码保护的 PBKDF2/AES-GCM 备份与恢复；用户主动导出就医摘要。
- 本地支持卡、身体求助、理解循环与安定练习；网络或AI失败不阻断记录。
- 设置中的「重新开始引导（重置App）」：确认后清空本设备数据与AI授权、取消安卓提醒并回到首次引导，提供先导出备份的入口。
- Android系统定时提醒；网页版提醒只在页面打开期间检查，不保证关闭后送达。
- PWA离线应用外壳，Android Capacitor工程，GitHub Pages及Android构建工作流。

## 开发

Node.js 22+（项目验证使用24）。

```sh
npm ci
npm run dev
npm run test:unit
npm run test:e2e
npm run build
```

默认网站基础路径 `/anyu/`。安卓构建设置 `APP_BASE=/`，然后执行 `npx cap sync android`。本机安卓构建需要 JDK 21、Android SDK；也可以使用 GitHub Actions。

## AI服务

浏览器/安卓 → 受邀请码保护的支持代理 → DeepSeek。`server/worker.mjs` 是可移植的无状态 Worker，`server/support-skill.md` 记录完整支持规则。记录回应用一句话，聊天通常80–200字。模型名由后端配置，默认 `deepseek-flash`。

服务端环境变量：`DEEPSEEK_API_KEY`、`ACCESS_CODE`、`DEEPSEEK_MODEL`、`ALLOWED_ORIGINS`。前端仅有公开的 `VITE_SUPPORT_ENDPOINT`，禁止任何 `VITE_*KEY` 或把 Key 放进静态网页。实际后端使用 Sites 管理密钥和 Worker 部署；前端仍在 GitHub Pages。

本地代理：`npm run server`。从父目录 `api.txt` 读取 Key 或从 `DEEPSEEK_API_KEY` 环境变量读取；本地邀请码默认 `local-development-only`，仅监听127.0.0.1。请勿把本地默认配置暴露到公网。

AI默认关闭，开启前展示最小化数据发送说明。代理不持久化对话，按邀请码认证、来源检查、请求体限制与每实例/每IP每分钟限流；这适合小范围内测，尚不具备生产级分布式配额、独立用户账户与完整运营治理。生产化前需增加持久化配额与临床内容评审。

## 数据边界

- 数据按设备隔离，不自动跨设备同步。清理网站数据或卸载可能丢失记录，请备份。
- 本地加密不能防止已获当前设备/应用访问权限的人读取解锁后的数据。
- 缺失记录是未知；0次仅代表当前已有记录，不代表真实完整发生率。
- 只有用户授权AI后才发送当前请求、目标、最多20条记录及12条对话；第三方处理政策在应用隐私说明中链接。
- 导入备份替换本机数据；邀请码不包含在备份中，AI授权需重新确认。

## Android 内测

当前APK用于侧载内测，不是应用商店正式发行版。正式发布前需生产签名、医疗内容专业审阅、隐私与适用备案准备、真机及可访问性验证。卸载前导出备份。

## 验证

单元检查覆盖全部30种计划、记录状态冲突、编辑去重、补填文案、代理认证、来源、危险信号、输入边界和单句回复。浏览器检查覆盖欢迎引导、记录增删改、刷新后保留、补填、求助入口与桌面布局。
